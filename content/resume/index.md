## Experience

{{< timeline >}}

{{< timelineItem header="Velocity Global" badge="2025 - Present" subheader="Senior Staff Cloud Infrastructure Engineer, Remote" >}}
Led a company-wide shift from a Lambda-centric stack to Kubernetes, GitOps, and Infrastructure
as Code. The organization had almost no container usage before this. I drove adoption by
upskilling the existing infrastructure team to co-own the platform, rolled out ArgoCD and
Terraform as standard practice, and stood up zero-trust network access (ZTNA) and just-in-time
production access to eliminate standing privileges.
{{< /timelineItem >}}

{{< timelineItem header="1Password" badge="2024 - 2025" subheader="Senior Staff Security Engineer, Vancouver, BC" >}}
Enabled 1Password to adopt Kubernetes and containers across AWS and GCP with a secure-by-default
framework. I led the migration from Lacework to Wiz for cloud security posture management, which
put visibility for both clouds under one platform. I also automated continuous CIS benchmark and
Terraform IaC scanning to catch weak configurations before they reached production.
{{< /timelineItem >}}

{{< timelineItem header="Ticketmaster" badge="2016 - 2024" subheader="Principal / Lead / Senior Systems Engineer, Remote" >}}
Grew from deploying Ticketmaster's first production Kubernetes cluster to leading technical
strategy for a fleet of 50+ clusters that ran most of the company's containerized workloads. I
wrote the company's first Kubernetes controller, saved over $1M/year in licensing by moving off
a commercial Kubernetes distribution, and mentored a distributed team that supported 50+
engineering teams. I also introduced Prometheus-based self-service monitoring and contributed to
several open-source projects in Go.
{{< /timelineItem >}}

{{< timelineItem header="Amazon Web Services" badge="2014 - 2016" subheader="Systems Engineer, EC2 Networking, Seattle, WA" >}}
On the EC2 Networking engineering org, I was the go-to VPC subject-matter expert and handled
substrate-level networking escalations. I built self-service diagnostic tooling that let AWS
Support run privileged networking tests via a simple API, which cut the engineering team's
escalation load.
{{< /timelineItem >}}

{{< timelineItem header="Oracle & earlier" badge="2009 - 2014" subheader="Systems, Virtualization & Network Security roles" >}}
Built a foundation in Unix/Linux systems, virtualization, and network security across roles at
Oracle, Softtek (GE Treasury), and the Universidad de Colima: Solaris and SPARC, private-cloud
automation, Juniper firewalls, and university-wide infrastructure.
{{< /timelineItem >}}
